Engineering Curricula & Wings

What We Work On

Discover the 12 specialized engineering verticals where EMBEDX members build hardware, write optimized firmware, automate machinery, and pioneer connected systems.

Silicon & Architecture

Embedded Systems

Design and deployment of specialized computing hardware and firmware engineered for deterministic, real-time operation in modern intelligent devices.

Core Focus: Embedded Hardware Design, Real-Time System Architectures, Memory Optimization.
ARM Cortex STM32 AVR Keil µVision Bare-Metal
Low-Level Systems

Embedded Software & RTOS

Low-level system programming, hardware abstraction layers (HAL), peripheral device drivers, and real-time operating system task scheduling.

Core Focus: C/C++ Low-Level Systems, Device Drivers, RTOS Multi-Tasking & Semaphores, ISR Timing.
Embedded C FreeRTOS Device Drivers POSIX GDB
Silicon Platforms

Microcontrollers & Processors

Hands-on mastery of 8-bit, 16-bit, and 32-bit computing platforms powering consumer, medical, automotive, and industrial electronics.

Core Focus: 8051, AVR ATmega, ARM Cortex-M0/M3/M4, PIC16/18, Raspberry Pi, ESP32.
8051 AVR ARM Cortex-M PIC ESP32
Connected Nodes

IoT & Edge Computing

Interconnecting physical edge sensor nodes to cloud backends through lightweight telemetry protocols and dashboards.

Core Focus: Cloud Telemetry (MQTT/HTTP), Edge Data Preprocessing, Sensor Pipelines.
MQTT CoAP Node-RED AWS IoT ThingSpeak
Autonomous Motion

Robotics & Automation

Kinematics, precision motion control, differential mobile rovers, robotic manipulators, and automated actuation.

Core Focus: Kinematics, Motor Drivers, PWM Control, Autonomous Path Planning & Obstacle Mapping.
Differential Drive PID Control Encoders Servos
Transducers

Sensors & Actuators

Instrumentation, signal conditioning, analog-to-digital conversion, and driver circuits for electromechanical actuators.

Core Focus: IMU Motion Sensing, Optical Probes, Ultrasonic Ranging, Solenoids & Relays.
MPU6050 IMU HC-SR04 ADC Sampling Load Cells
System Dynamics

Control Systems

Mathematical modeling, closed-loop feedback design, PID tuning, and state-space control for stable dynamic responses.

Core Focus: Closed-Loop Feedback, PID Tuning, State Observers, Bode & Stability Analysis.
MATLAB Simulink PID Tuning State-Space
Industry 4.0

PLC & Industrial Automation

Industrial automation, Programmable Logic Controllers (PLC), SCADA supervision, and HMI for manufacturing lines.

Core Focus: Ladder Logic (LD), SCADA & HMI Supervision, Relay Interlocks, Modbus TCP/RTU.
Siemens S7 Allen-Bradley SCADA TIA Portal
Hardware Prototyping

PCB Design & Prototyping

Schematic capture, multi-layer printed circuit board routing, component footprint creation, DRC, and Gerber generation.

Core Focus: Schematic Capture, Trace Routing, Ground Planes, Signal Integrity, DFM.
Altium Designer KiCad Proteus Gerber CAD
Telemetry & RF

Wireless Communication

RF transceiver integration, short-range wireless meshes, and long-range low-power radio communication protocols.

Core Focus: Bluetooth Low Energy (BLE), Wi-Fi 802.11, LoRa / LoRaWAN, NRF24L01+ RF Telemetry.
LoRaWAN BLE 5.0 Wi-Fi NRF24L01
Instrumentation

Data Acquisition & Analytics

High-speed measurement, automated test bench instruments, signal processing, and engineering telemetry logging.

Core Focus: Multi-Channel DAQ, Digital Signal Processing (FFT), Virtual Instruments.
LabVIEW MATLAB VISA/GPIB Signal Processing
Embedded AI

AI at the Edge (TinyML)

Quantized machine learning models deployed directly on microcontrollers for on-device voice, anomaly detection, and vision.

Core Focus: TinyML Quantization, On-Device Anomaly Detection, Embedded Vision, Neural Acceleration.
TensorFlow Lite Edge Impulse CMSIS-NN OpenMV
Toolchains & Software

Tools & Platforms We Utilize

Industry-standard software suites, IDEs, simulation packages, and hardware platforms used in EMBEDX project sprints.

Keil µVision

Industry-standard ARM & 8051 compiler and simulator.

STM32CubeIDE

Comprehensive C/C++ development platform for STM32 MCUs.

Arduino IDE

Rapid prototyping and multi-board firmware flashing.

Raspberry Pi & Linux

Embedded Linux, Python automation, and edge telemetry.

MATLAB / Simulink

Mathematical modeling, dynamic simulation, and PID tuning.

LabVIEW

Virtual instrumentation and automated data acquisition.

Proteus & Multisim

SPICE electronic circuit simulation and MCU co-simulation.

Altium & KiCad

Professional schematic capture and multi-layer PCB layout.
